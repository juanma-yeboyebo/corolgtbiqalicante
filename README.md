# Coro LGTBIQ+ Alicante — área privada

Web estática para GitHub Pages con una contraseña común para entrar.

## Añadir una canción

1. Sube los ficheros a `canciones/<Nombre de la canción>/`.
2. Añade la canción en `canciones.js`, copiando uno de los bloques que ya hay.

## Publicar

En GitHub: Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Probar en local

Abrir `index.html` en el navegador.
